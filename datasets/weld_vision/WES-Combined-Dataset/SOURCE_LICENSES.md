# Source and License Notes

This combined directory does not replace the source datasets' terms. Review the original source pages and files before redistribution or commercial use.

## Supervised sources

- `Weld-bead-images-and-masks`: official Figshare record `10.6084/m9.figshare.25904014.v1` lists the dataset as MIT. The local copy was obtained through a Kaggle mirror because the Figshare CDN returned an access challenge; the internal structure matches the official description (1,394 image/mask pairs and `train.csv`).
- `welding_spots_100`: Kaggle dataset `qrsforever/welding-spots-100`, listed as Apache 2.0 when downloaded.

## Auxiliary detection sources

- `Weld-Defect-Dataset-main`: the local repository includes an MIT `LICENSE` file.
- `The-Welding-Defect-Dataset-main`: no explicit license file or clear dataset license was found locally. Treat this source as restricted/unknown until its upstream terms are confirmed. It is included only as an auxiliary unlabeled pool and is not segmentation ground truth.

## Excluded source

- `3D_Laser_Vision_Welding_Robot-main` and its ZIP archive are excluded from this combined dataset.
