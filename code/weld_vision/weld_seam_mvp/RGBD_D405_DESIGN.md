# RealSense D405 选型、安装与三维转换设计

## 1. 结论

本项目建议使用 **RealSense D405**，采用机器人前上方、横向居中、向前俯视的刚性安装方式。

本文描述顶部主相机。滑轨探头位置的第二台 D405、动态外参和控制接口见项目文档 `docs/PROBE_CAMERA_AND_RAIL.md`。

推荐机械初值：

- 相机光心相对机器人表面坐标系：`[0.135, 0.000, 0.200] m`
- 横向位置：机器人中心线 `Y=0`
- 光轴：从指向钢板的法向向机器人 `+X` 前方倾斜 `35 deg`
- 推荐采集：彩色与深度 `1280x720 @ 30 fps`
- 深度必须用 RealSense SDK 对齐到彩色图，再交给焊缝模型

这里的位姿矩阵是可用于软件联调的**机械设计初值**，不是装机标定结果。安装支架、相机外壳和机器人基准的制造误差会直接变成三维轨迹误差，因此真机必须重新标定外参。

## 2. 为什么选择 D405

D405 的官方主要规格包括：

- 理想测距范围：`0.07-0.50 m`
- 深度视场：`87 deg x 58 deg`
- 全局快门
- 深度最高分辨率：`1280x720`
- 通过左深度传感器和 ISP 提供 RGB，最高 `1280x720 @ 30 fps`
- 尺寸约 `42 x 42 x 23 mm`
- 重量约 `60 g`
- SDK 支持 Linux 和 Python，并有 ROS 2 wrapper

机器人法向高度约 225 mm，相机光心设计在离钢板约 200 mm 处。这个工作距离落在 D405 的近距离优势区间内。D435/D455 更偏向中远距离场景，在当前紧凑机身上没有 D405 合适。

资料来源：

- [RealSense D405 官方产品页](https://realsenseai.com/stereo-depth-cameras/stereo-depth-camera-d405/)
- [librealsense SDK](https://github.com/realsenseai/librealsense)
- [RealSense ROS 2 wrapper](https://github.com/realsenseai/realsense-ros)
- [RealSense 投影模型说明](https://dev.realsenseai.com/docs/projection-in-intel-realsense-sdk-20)

## 3. 安装设计

### 3.1 坐标系

`base_surface` 固连机器人：

- 原点：机器人几何中心在钢板表面的投影
- `+X`：机器人前进方向
- `+Y`：机器人左侧
- `+Z`：离开钢板表面

`camera_color_optical_frame`：

- `+Xc`：图像向右
- `+Yc`：图像向下
- `+Zc`：光轴向前

### 3.2 支架建议

- 将相机放在机器人前上部，横向严格居中，减少左右方向外参耦合。
- 用刚性铝合金支架连接机架，优先使用两个 M3 定位/固定点以抑制转动；若使用 1/4-20 安装孔，应增加止转结构。
- 支架提供固定的 35 deg 倾角，不依赖可松动的摩擦铰链。
- 设置 USB 线应力释放，线缆弯曲力不能传给相机外参。
- 增加遮光罩和可更换保护结构。任何保护窗都可能影响双目红外成像，材料、厚度、倾角和反射必须在真实工作距离下重新验证。
- D405 不是焊弧专用、也不能默认具备项目需要的 IP 防护。安装位置应避开飞溅，并与焊枪工作区保持机械安全距离。

把 `42 x 42 x 23 mm` 外壳近似为以光心为中心的长方体，在推荐姿态下估算包络为：

- `X: 111.2-158.8 mm`
- `Y: -21.0-21.0 mm`
- `Z: 178.5-221.5 mm`

该估算位于 `319 x 422 x 225 mm` 机器人包围盒内，但真实光心相对外壳的位置、接插件和支架尺寸仍需在机械 CAD 中复核。

## 4. 视场与工作距离

机器人前缘约为 `X=319/2=159.5 mm`。按光心高度 200 mm、俯视角 35 deg、垂直视场 58 deg 计算，视场射线与钢板相交位置为：

| 位置 | 钢板上的 X | 相机 Z 深度 | 相对机器人前缘 |
|---|---:|---:|---:|
| 近端 | 156.0 mm | 201.1 mm | -3.5 mm |
| 中心 | 275.0 mm | 244.2 mm | +115.5 mm |
| 远端 | 545.1 mm | 456.2 mm | +385.6 mm |

这些中心射线深度均位于 D405 的 70-500 mm 理想范围内。中心位置按水平视场 87 deg 估算横向覆盖约 463.4 mm，略大于机器人 422 mm 宽度。

上述计算采用官方标称视场，只用于安装可行性检查。真机输出点云应使用每台设备、每个分辨率下由 SDK 返回的真实内参。

## 5. 三维矩阵转换

对彩色图上的中心线点 `(u, v)`，从已经对齐到彩色图的深度图读取光轴深度 `d`。去畸变后的归一化坐标为 `(xn, yn)`：

```text
Pc = [xn*d, yn*d, d]^T
Pb = R_base_camera * Pc + t_base_camera
```

推荐机械初值 `T_base_camera` 为：

```text
[[ 0.000000000, -0.819152044,  0.573576436, 0.135],
 [-1.000000000,  0.000000000,  0.000000000, 0.000],
 [ 0.000000000, -0.573576436, -0.819152044, 0.200],
 [ 0.000000000,  0.000000000,  0.000000000, 1.000]]
```

含义是：

```text
P_base = T_base_camera * P_camera
```

实现位于 `weld_seam/rgbd_geometry.py`。算法还包含：

- 中心线像素邻域的有效深度中值，恢复单像素深度孔洞
- 深度范围门控，默认 `0.07-0.50 m`
- 局部深度 MAD 门控，拒绝反光导致的不稳定区域
- 钢板表面 `|base_z|` 门控，默认 35 mm
- 保留原二维中心线索引，输出 JSON 和 CSV 有序三维曲线

平面钢板可启用 `base_z` 门控；曲面工件应在配置中设为 `null`，或改为相应曲面模型的距离门控。

## 6. 真机标定步骤

1. 固定相机、支架和线缆，之后不得改变相机位姿。
2. 用 `capture_realsense_rgbd.py` 读取该设备在实际流配置下的内参和 `depth_scale`，不要手填标称值。
3. 在机器人 `base_surface` 中布置坐标已知的 AprilTag 板或棋盘格。靶板应覆盖工作视场和工作距离，不能只采一张正视图。
4. 用 OpenCV `solvePnP` 求靶板到相机的位姿；由已知的靶板到机器人位姿组合得到 `T_base_camera`。
5. 采多姿态数据联合优化，替换 `config/d405_mount.yaml` 中的机械初值矩阵。
6. 用独立验证点检查三维误差，并统计钢板平面 `base_z` 残差。MVP 可先以 `<5 mm` 为工程验收起点，最终阈值必须由焊缝跟踪精度要求决定。
7. 如果保护窗、相机焦距/分辨率、支架或安装位置发生变化，重新标定和验证。

## 7. 焊接现场风险

双目深度在高反光、低纹理、焊弧强光和烟尘下可能产生孔洞或跳点。当前软件会拒绝缺失和局部离散过大的深度，但不能凭算法保证所有现场帧有效。

真机阶段建议依次验证：停弧冷态钢板、补充照明、焊弧开启、烟尘和飞溅条件。然后再决定曝光/HDR、红外投射、窄带滤光、遮光罩、时间滤波和机器人降速策略。无有效三维点或有效率过低时，控制系统必须保持上一条可靠轨迹或停车，不能把空曲线直接送给执行机构。
